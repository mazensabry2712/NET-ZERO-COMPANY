# Net Zero Company — Corporate Website Proof of Work

A modern corporate website concept for the Net Zero industrial group, based on the supplied SOW and the supplied Net Zero logo. The visual direction is inspired by modern industrial energy platforms, with SMA used as a visual benchmark rather than a copy.

## Quick preview — no installation needed

Double-click `index.html` and open it directly in a browser.

## Development mode

```bash
npm install
npm run dev
```

## Included

- `index.html` — standalone homepage
- `src/styles.css` — complete responsive styling
- `src/main.js` — browser-ready interactions for direct preview
- `src/main.ts` — TypeScript source
- `public/logo.png` — supplied logo
- `package.json` + `tsconfig.json` — optional Vite/TypeScript workflow
